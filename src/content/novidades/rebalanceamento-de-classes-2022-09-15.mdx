---
title: "Rebalanceamento de Classes - 15/09/2022"
date: "2022-09-15"
---

<ul>
  <li>
    <strong class="gold-title">Armas de Arremesso</strong>
    <ul>
      <li>Ser Veterano(a) não é mais um requisito para utilizar Armas de Arremesso;</li>
      <li>
        Todas as classes continuam podendo utilizar arremessos, porém agora
        a maioria só libera o acesso no nível 3 (com exceção das classes
        Sicário e Viking), que passaram também a ter mais arremessos do que
        antes (mais informações abaixo);
      </li>
      <li>
        Textos das páginas Equipamentos e [Progressão &gt; Novato x
        Veterano] atualizados de acordo com as novas regras.
      </li>
    </ul>
  </li>
  <li>
    <strong class="gold-title">Armas Extras</strong>
    <ul>
      <li>
        As Classes que possuem Armas Extras deverão a partir de agora optar
        entre utilizar a Arma Extra ou o Arremesso (mais informações
        abaixo).
      </li>
    </ul>
  </li>
  <li>
    <strong class="gold-title">Classes</strong>
    <ul>
      <li>
        <a class="links-de-texto" href="/arqueiro">Arqueiro</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3. Deverá optar entre utilizar sua Arma Extra ou o Arremesso;</li>
          <li>- Arma Extra: Antes o Arqueiro podia utilizar qualquer Arma Curta como Arma Extra, agora pode somente utilizar uma Adaga ou Espada Curta no Nível 1. A Melhoria de Arma Extra no Nível 3 permanece a mesma;</li>
          <li>- Atirador de Elite: A menção dessa conquista foi removida temporariamente até que o sistema de conquistas seja lançado. A ideia é que o Arqueiro passe a poder carregar mais 2 flechas/setas, totalizando 10.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/barbaro">Bárbaro</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/cavaleiro">Cavaleiro</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3. Deverá optar entre utilizar sua Arma Extra ou o Arremesso;</li>
          <li>- Arma Extra: Antes o Cavaleiro podia utilizar qualquer Arma Curta como Arma Extra, agora pode somente utilizar uma Adaga ou Espada Curta;</li>
          <li>- Escudo Extra: O Escudo Pequeno adquirido no Nível 3 ainda pode ser utilizado com a Arma Extra ou o Arremesso.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/espadachim">Espadachim</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/guerreiro">Guerreiro</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/hoplita">Hoplita</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3. Deverá optar entre utilizar sua Arma Extra ou o Arremesso;</li>
          <li>- Arma Extra: Agora o Hoplita pode também utilizar uma Adaga como Arma Extra, podendo escolher entre Adaga ou Espada Curta.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/lanceiro">Lanceiro</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3. Deverá optar entre utilizar sua Arma Extra ou o Arremesso;</li>
          <li>- Arma Extra: A classe Lanceiro não tem mais acesso a uma Arma Média Extra no Nível 3;</li>
          <li>- Arma Extra: Antes o Lanceiro podia utilizar qualquer Arma Curta como Arma Extra, agora pode somente utilizar uma Adaga ou Espada Curta;</li>
          <li>- Escudo Extra: O Escudo Pequeno adquirido no Nível 3 ainda pode ser utilizado com a Arma Extra ou o Arremesso.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/sicario">Sicário</a>
        <ul>
          <li>- Nível 1: O Sicário agora tem acesso a 2 arremessos (antes tinha 1);</li>
          <li>- Nível 3: O Sicário ganha mais um arremesso, totalizando 3 arremessos;</li>
          <li><strong class="gold-title">OBS:</strong> Em duelos, torneios e modalidades que restrinjam o uso de arremessos, o Sicário poderá utilizar 2 arremessos (antes era 1), mesmo que seja nível 3.</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/templario">Templário</a>
        <ul>
          <li>- Arremesso: Pode utilizar uma Arma de Arremesso no nível 3. Deverá optar entre utilizar sua Arma Extra ou o Arremesso;</li>
          <li>- Arma Extra: Antes o Templário podia utilizar qualquer Arma Curta como Arma Extra, agora pode somente utilizar uma Adaga ou Maça Curta. Agora pode também utilizar uma das Armas Extras citadas na combinação de Mangual e Escudo (antes podia somente ao utilizar Maça Longa).</li>
        </ul>
      </li>
      <li>
        <a class="links-de-texto" href="/viking">Viking</a>
        <ul>
          <li>- Nível 1: O Viking tem acesso a 1 arremesso;</li>
          <li>- Nível 3: O Viking ganha mais um arremesso, totalizando 2 arremessos;</li>
          <li><strong class="gold-title">OBS:</strong> Em duelos, torneios e modalidades que restrinjam o uso de arremessos, o Viking poderá utilizar 1 arremesso, mesmo que seja nível 3.</li>
        </ul>
      </li>
    </ul>
  </li>
</ul>
