## Combinações de Armas

<p><strong class="gold-title">Legenda:</strong> <strong class="short">(C)</strong> = Curta / <strong class="medium">(M)</strong> = Média / <strong class="large">(L)</strong> = Longa.</p>
<ul class="lista-comum">
  <li>Machado / Martelo <strong class="short">(C)</strong> + Machado / Martelo <strong class="short">(C)</strong>;</li>
  <li>Machado / Martelo <strong class="medium">(M)</strong> + Machado / Martelo <strong class="short">(C)</strong>;</li>
  <li>Machado / Martelo <strong class="medium">(M)</strong> + Machado / Martelo <strong class="medium">(M)</strong>;</li>
  <li>Machado / Martelo <strong class="large">(L)</strong> (duas mãos).</li>
</ul>
<p><strong class="gold-title">Arma Extra:</strong> Uma Adaga <strong class="short">(C)</strong>, Machado <strong class="short">(C)</strong> ou Martelo <strong class="short">(C)</strong> pode ser adicionado na combinação de Machado / Martelo <strong class="large">(L)</strong> (duas mãos).</p>
<p><strong class="gold-title">OBS:</strong> A Arma Extra serve para quando o combate fica muito próximo, quando o Bárbaro perde um braço (por ser mais leve e fácil de usar com uma mão só) ou quando é desarmado. Deve preferencialmente ficar embainhada.</p>

## Bônus de Nível 3

<ul class="lista-comum">
  <li><strong class="gold-title">Nova combinação:</strong> Machado / Martelo <strong class="large">(L)</strong> + Machado / Martelo <strong class="short">(C)</strong> ou <strong class="medium">(M)</strong>;</li>
  <li><strong class="gold-title">Arma de Arremesso:</strong> Passa a poder carregar uma Arma de Arremesso.</li>
</ul>
<p><strong class="gold-title">Arma Extra x Arremesso:</strong> Se o Bárbaro usar a segunda arma como Arma Extra (embainhada) na combinação de Machado / Martelo <strong class="large">(L)</strong>, deverá escolher entre portar a Arma Extra ou o Arremesso. Ao portar como Arma Extra, o Machado / Martelo deverá ser de tamanho <strong class="short">(C)</strong>.</p>

<details class="classe-bloco">
  <summary>Como se joga</summary>
  <ul class="lista-comum">
    <li>O machado costuma acertar mesmo quando o golpe é defendido, então vai bem contra Templário, Guerreiro e Viking;</li>
    <li>Combina com quem gosta de um estilo mais bruto de luta, dentro do que o Swordplay permite de força;</li>
    <li>Usar uma arma em cada mão é o melhor jeito de treinar ambidestria.</li>
  </ul>
</details>

<details class="classe-bloco">
  <summary>Origem da classe</summary>
  <p>Bárbaro era como os gregos chamavam quem não falava o idioma deles, e depois os romanos adotaram o mesmo termo. Os primeiros rotulados assim no Império Romano foram os povos germânicos.</p>
  <p>A imagem que ficou, do lutador bruto que tira força da raiva, veio bem mais dos RPGs do que da história. No Dragon Style a classe herdou essa fama e ficou com os machados duplos, machados longos e martelos.</p>
</details>
